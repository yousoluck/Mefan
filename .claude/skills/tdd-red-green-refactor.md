# TDD 操作指南
- 触发条件：开发者执行编码任务。
- 适用 Agent：开发者

## 红灯阶段
1. 阅读测试计划，找到本任务的测试用例。
2. 编写一个最小化的、当前会失败的测试。
3. 执行测试，确认红灯。
4. 提交测试代码（即使失败，记录到 task-summary）。

## 绿灯阶段
1. 编写刚好让测试通过的最小代码，不管优雅程度。
2. 执行测试，确认绿灯。

## 重构阶段
1. 消除重复代码。
2. 优化命名。
3. 确保与一致性基线对齐。
4. 确认所有测试依然绿灯。

## 禁止事项
- 禁止先写实现再补测试。
- 禁止跳过红灯直接写实现。
