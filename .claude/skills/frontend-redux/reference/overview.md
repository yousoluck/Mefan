## 核心概念
- Store: 单一数据源
- Action: 状态变更的描述
- Reducer: 根据 Action 计算新状态
- Dispatch: 触发 Action 的方法
- Selector: 从 State 读取数据

## 最佳实践
- 使用 Redux Toolkit 简化代码
- 使用 TypeScript 定义类型
- 使用 createAsyncThunk 处理异步
- 使用 createSlice 减少样板代码
- 使用 reselect 创建 memoized selectors
