# Code Review 审查清单
- 适用 Agent：守护者

## 语义正确性
- [ ] 代码是否实现了 ADR 描述的功能？
- [ ] 是否有遗漏的边界情况？

## 安全性
- [ ] 是否有未验证的用户输入直接拼接到 SQL/命令？
- [ ] 是否有明文密钥或 token？
- [ ] 权限检查是否完整？

## 性能
- [ ] 是否有循环内数据库查询？
- [ ] 是否有不必要的大对象拷贝？

## 一致性
- [ ] 命名是否与参考模块一致？
- [ ] 错误处理范式是否与基线一致？
- [ ] 目录放置是否符合项目规范？

## 可维护性
- [ ] 是否有可提取的重复代码？
- [ ] 函数复杂度是否过高？
