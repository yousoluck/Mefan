# 异常处理片段（所有 Agent 复用）

> 本文件为共享片段，所有 Agent 在执行时遇到异常情况应参照此表处理。
> 在 Agent 文件的 ## 异常处理 部分引用：`!.claude/snippets/exception-handling.md`

## 通用异常处理表

| 异常场景 | 处理方式 | 优先级 |
|---------|---------|--------|
| 同一任务 Hook 拦截 ≥ 3 次 | 暂停任务，评估是否回溯设计，通知 PM | P0 |
| 设计冲突无法裁决 | 生成《裁决申请书》，提交 PM 升级给人类 | P0 |
| P0 Bug 发现 | 立即暂停当前迭代其他编码任务 | P0 |
| 进度滞后（实际 < 计划 × 0.7） | PM 提案缩小范围，提交人类决策 | P1 |
| graphify 查询失败 | 标注"手动分析"继续，不报错 | P2 |
| 依赖文件未发现 | 标注"人工补充"，向用户询问技术栈 | P2 |

## 阶段特定异常

### 阶段 0 异常

| 异常场景 | 处理方式 |
|---------|---------|
| SCENARIO 未定义 | 报错退出 |
| 迭代目录未创建 | 报错退出 |
| PM 校验重试 3 次仍失败 | 提交 Human Gate |

### 阶段 3 异常

| 异常场景 | 处理方式 |
|---------|---------|
| 核心冲突无法裁决 | 生成《裁决申请书》，提交 Human Gate |
| 任务 WIP 超出限制 | 提案调整，提交 Human Gate |

### 阶段 4 异常

| 异常场景 | 处理方式 |
|---------|---------|
| TDD 测试失败 | 开发者修复，不进入下一任务 |
| Hook 拦截 ≥ 3 次 | 暂停任务，通知 PM |

## 异常记录规则

1. 所有异常必须记录到 `session-status.md` 的"异常记录"章节
2. 记录格式：
   ```
   | 时间 | 异常类型 | 描述 | 决策 | 结果 |
   ```
3. P0 异常必须立即通知 PM，不等待下一个 Human Gate
