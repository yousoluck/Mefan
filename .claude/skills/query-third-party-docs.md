# 第三方依赖查询
- 触发条件：阶段 4 实现任务时需要使用新依赖
- 适用 Agent：开发者

## 输入
- 需要查询的依赖名称（如 `axios`, `lodash`）
- 需要的功能描述（如"HTTP 客户端"、"日期处理"）

## 输出
- 推荐的依赖版本号
- 关键 API 用法记录
- 记录到 task-summary 的"依赖变更"章节

## 操作步骤

### 1. 确定查询优先级
**优先级顺序**：
1. 官方文档（权威、完整）
2. GitHub README（示例丰富）
3. Stack Overflow（实践验证）
4. 博客教程（谨慎参考）

### 2. 查询步骤
```
1. 访问官方文档站
   - npm: https://docs.npmjs.com/
   - Maven: https://maven.apache.org/guides/
   - PyPI: https://pypi.org/

2. 搜索目标依赖
   - 确认最新稳定版本
   - 查看 Breaking Changes（若从旧版本升级）

3. 记录关键信息
   - 包名 + 版本范围
   - 核心 API 签名
   - 使用示例代码
```

### 3. 版本选择策略
| 场景 | 策略 |
|------|------|
| 新项目 | 使用最新稳定版 |
| 已有项目升级 | 查看 CHANGELOG，评估迁移成本 |
| 安全优先 | 指定具体版本，不用 `latest` / `*` |

### 4. 记录到 task-summary
```
## 依赖变更
- 新增依赖：`package@version`，用途：`功能描述`
  - 关键 API：`API名称（参数） -> 返回值`
  - 参考文档：https://...
```

## 禁止事项
- 禁止臆造 API（没查过的用法不能直接写）
- 禁止使用非 LTS 或明确已废弃的依赖
- 禁止引入与现有技术栈冲突的依赖
