# 异常处理流程
- type: constraint
- severity: error

## 连续 Hook 拦截
- 第 1 次：开发者参考违规列表自行修复。
- 第 2 次：开发者必须生成 `interception-analysis.md`。
- 第 3 次：暂停任务，PM 评估是否回溯设计或人工介入。

## 进度严重滞后
- 触发条件：实际完成度 < 计划完成度 × 0.7。
- PM 自动生成精简提案（缩小范围/延期），提交人类决策。

## P0 缺陷发现
- 立即暂停当前所有其他开发任务。
- 开发者优先修复 P0 缺陷。
- 修复后重新测试，通过后恢复其他任务。

## 设计冲突无法裁决
- PM 生成《裁决申请书》提交人类。
