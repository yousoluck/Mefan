### 2.4 Modular Group 分组与依赖 [必填]
> 本节定义 US 之间的依赖关系和 Modular Group 划分，供阶段 3 迭代计划使用

#### 2.4.1 Modular Group 划分

| Group ID | Group 名称 | 包含 US | 依赖关系 | 可独立开发 | 说明 |
|----------|-----------|---------|----------|-----------|------|
| MG-001 | {功能名称} | US-01, US-02 | 无 | ✅ | 后端 API + 前端 UI 打包 |
| MG-002 | {功能名称} | US-03 | 依赖 MG-001 | ❌ | 依赖前置 Group 的数据模型 |

#### 2.4.2 US 依赖矩阵

| US | 依赖 US | 被依赖 US | 可独立开发 |
|----|---------|-----------|-----------|
| US-01 | - | US-02, US-03 | ✅ |
| US-02 | US-01 | US-04 | ❌ |
| US-03 | US-01 | - | ❌ |

**划分原则**：
1. 按业务边界划分 Group，同一 Group 内包含相关的后端 API + 前端 UI
2. 被依赖的 Group 先开发，依赖的 Group 后开发
3. 可独立开发的 Group 可并行执行
4. 每个 Group 应能在 1-2 天内完成开发

#### 2.4.3 开发顺序建议

```
MG-001 (可独立) → MG-002 (依赖 MG-001) → MG-003 (依赖 MG-001, MG-002)
     ↑                    ↑
   并行                   串行
(如果多 Dev)
```

### 15.1 数据迁移方案

#### 迁移脚本路径
- **正向迁移**：`db/migration/V{日期}__{描述}.sql`
- **回滚脚本**：`db/migration/V{日期}__rollback.sql`

#### 迁移步骤
1. 备份相关表数据
```sql
CREATE TABLE {table}_backup AS SELECT * FROM {table};
```
2. 执行迁移脚本
```bash
flyway migrate
```
3. 验证数据完整性
```sql
SELECT COUNT(*) FROM {table};
```

#### 数据验证SQL
```sql
-- 验证外键约束
SELECT * FROM {table} WHERE {condition};
-- 验证数据量
SELECT COUNT(*) FROM {table};
```

#### 回滚方案
```sql
DROP TABLE IF EXISTS {table};
```
